# Предложение по редизайну, 13.11.2026

Основание — [`UI-AUDIT-2026-11-13.md`](UI-AUDIT-2026-11-13.md). Ограничения соблюдены: статический HTML/CSS, без сборщика, фреймворков и CDN; контент, БД, `scripts/check-*.mjs` не трогаем; одна правка — один коммит.

Цель редизайна — не «современно», а **быстрее до конспекта**: на 390 px первый экран должен показывать дисциплины, конспект должен читаться строкой 45–75 знаков (на телефоне 38–42), а все 12 страниц должны выглядеть как один продукт.

## Принципы

1. **Первый экран — рабочее место, а не витрина.** Шапка ≤ 56 px, заголовок страницы 24 px, под ним сразу то, за чем пришёл: дисциплины на главной, поиск и список на билетах. Реклама контента («Удобные структурированные конспекты…») уходит из шапки в `meta description` и пустые состояния.
2. **Чтение — главный сценарий.** Мера строки 45–75 знаков на планшете и ПК (на телефоне 38–42 — больше не влезает), `text-align: left`, `line-height: 1.6`. Выключка по ширине запрещена: на 32–43 знаках она даёт «реки», а не выравнивание.
3. **Одна сетка и одна шапка на 12 страниц.** Один `.container` 1200 px, один `.page-head`, один левый край у заголовка и у первой карточки. Разные ширины (`520…1400`) и разные шапки (inline, centered, practice) — причина «прыжков» между страницами.
4. **Компонент = состояние.** Кнопка, поле, карточка, папка, модалка описываются матрицей `default / hover / active / focus-visible / disabled`. `active` и `hover` не могут выглядеть одинаково.
5. **Токены вместо магических чисел.** Один `:root` (цвет, кегль, шаг, радиус, тень, мера, брейкпоинт). Правило «на будущее»: новое значение в CSS — только через токен.

## Компоненты

### Шапка `.topbar` + `.page-head`

Правило: **шапка принадлежит странице, а не контенту**. Никаких inline-стилей; `index.html:37-58` переезжает в CSS-классы.

- `.topbar` — 56 px (44 px на ≤480): слева бренд-ссылка (иконка 24 + название 16/700), справа чип ID (44 px, `--r-pill`, `--line-strong`).
- `.page-head` — под шапкой, `padding-top: 24px`, ширина `--measure`: `h1` 24/700 (20/700 на ≤480), подпись 14/1.45 `--ink-2`, **одна**, не больше двух строк. `h2`-лозунг удаляется (см. «Страница за страницей»).
- Возврат: `a.back` = иконка `←` + «Меню», 44 px, внутри `.page-head` над `h1`, а не отдельной капсулой 64 px.

### Кнопки

| Вариант | Фон / текст | Рамка | Где |
|---|---|---|---|
| `primary` | `--accent` / `#fff` | нет | «Открыть билет», «Проверить», «Разрешить аналитику» |
| `secondary` | `--surface` / `--ink` | 1 px `--line-strong` | «Только необходимое», «Повторить», «К списку» |
| `ghost` | прозрачный / `--accent` | нет | «Показать критерии», второстепенные действия |
| `danger` | `--danger-bg` / `--danger` | 1 px `--danger` | «Отозвать согласие» |

Общее: высота 44 px, `--r-md` (10 px), 14/600, `padding: 0 20px`, `gap: 8px` между кнопками. На ≤480 главное действие — `width:100%`.
Состояния: `hover` — `--accent-hover`; `active` — `translateY(1px)`; `focus-visible` — `outline: 3px solid var(--focus); outline-offset: 2px`; `disabled` — `opacity:.5; cursor:not-allowed` без смены цвета текста (контраст не гарантируется, но состояние читаемо).

### Карточки и плитки

- `.card` — `--surface`, 1 px `--line`, `--r-lg`, `padding: 20px`, `--shadow-1`.
- `.tile` (меню, книги) — сетка `repeat(auto-fill, minmax(260px, 1fr))`, `gap: 16px`; иконка 24 px (SVG, не эмодзи 36 px); заголовок 18/700; описание 14/1.5 **`text-align:left`**, `margin:0`; минимальная высота 120 px. Никакой типографики конспекта (убрать `.menu-item p` из селектора `.content-text`, U-26).
- `.lead` (дисциплина на главной) — строка 88 px: название 18/700, мета 13 `--ink-3`, справа «Открыть →»; вся строка — ссылка, `hover` — `--accent-soft`.
- `.nav-item` (папка/вопрос) — 44 px минимум, 14/500, `--r-md`; **selected** — `--accent` + белый + левый бар 3 px; **hover** — только `--accent-soft`. Разные состояния (U-17).

### Текст конспекта и статьи

```css
.content-text {
  max-width: var(--measure);      /* 62ch ≈ 535 px, 65 знаков */
  font-size: var(--fs-16);
  line-height: var(--lh-body);    /* 1.6, не 1.8 */
  color: var(--ink);
  text-align: left;               /* justify убран */
  hyphens: auto;
  overflow-wrap: anywhere;
}
.content-text h3 { font-size: var(--fs-20); margin: var(--s-7) 0 var(--s-3); }
.content-text h4 { font-size: var(--fs-16); margin: var(--s-5) 0 var(--s-2); color: var(--ink-2); }
.content-text p  { margin: 0 0 var(--s-4); }
```

Мера — на тексте, карточка остаётся 900 px. Замерено в браузере: `62ch` = 535 px при 16 px Segoe UI = **65 знаков**. На 1024 при той же колонке текст сжимается до 460 px (56 знаков), на 390 — 340 px (42 знака, нижняя граница нормы).

### Поля и формы

`input`, `select`, `textarea` — 44 px, `--r-md`, 1 px `--line-strong`, `padding: 0 12px`, 16 px (на iOS не зумит), фон `--surface`; `focus` — рамка `--accent` + `box-shadow: 0 0 0 3px rgba(43,108,176,.18)`; `::placeholder { color: var(--ink-3) }` (сейчас стиля нет вовсе). Чекбокс — `accent-color: var(--accent)`, зона нажатия — весь `label` с `min-height: 44px`.

### Модалки

Оверлей `rgba(16,24,40,.5)`, панель 520 px max, `--r-lg`, `padding: 24px`, `--shadow-2`, `max-height: 90dvh`, `overflow-y: auto`. Обязательно: `body.modal-open { overflow: hidden }` (сейчас блокирует только модалка закладок), `role="dialog" aria-modal="true"`, `Esc`, focus trap, возврат фокуса на триггер, `✕` 44×44. Мобильная версия — нижний лист с `--r-lg 18px 18px 0 0`.

### Состояния

- **Пустое** — `.empty`: иконка 32, заголовок 18/700, текст 14/1.5 `--ink-2`, кнопка `secondary`. Один компонент вместо четырёх (U-34).
- **Загрузка** — скелетон: 3 строки 14 px, `--line`, без «прыжка» (фиксированная высота блока).
- **Ошибка** — карточка `.error` с `--danger-bg`, текст `--danger`, кнопки `secondary` «Повторить» и `ghost` «На главную». Плашка «показаны сохранённые» — полоса 48 px **под** шапкой, не над навигацией (U-21).
- **Тост** — снизу справа, 360 px, `--r-md`, `--shadow-2`, 14 px, `✕` 44 px; сдвигается вверх на высоту плашки согласия. Не занимает правый верхний угол, где стоит кнопка ID (U-20).
- **Печать** — плашки без фона, с рамкой 0.5 pt; `h4` 12 pt/700; скрывать подвал/навигацию/кнопки (уже сделано).
