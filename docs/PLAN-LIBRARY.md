# Библиотека: что делать с функционалом (U2-16)

**Источник:** «работа с интерфейсом.docx» — «мне не нравится её функционал, но пока ничего не могу придумать».
**Ответ автора (01.11.2026):** пользователь должен мочь найти литературу, которую дают преподаватели, лучше подготовиться к экзаменам или просто ознакомиться с интересующими материалами.
**Статус:** ТЗ. Код не начат, оценка после согласования.

---

## 1. Что есть сейчас

`library.html` рисует все книги одной сеткой карточек в алфавитном порядке: автор — название, аннотация (`js/news-library.js:18-39`). Данные — таблица `library` (`id, title, author, annotation`), связи «билет → книга» — `ticket_library` (`ticket_id, book_id`).

Что это не решает при трёх названных сценариях:

| Сценарий | Что мешает |
|---|---|
| «Найти литературу, которую дают преподаватели» | Нет поиска и фильтров: 60+ карточек глазами, без группировки по дисциплине |
| «Подготовиться к экзамену» | Список литературы по билету есть только внутри конспекта и никуда не ведёт; из библиотеки не видно, к каким билетам относится книга |
| «Ознакомиться с интересующим материалом» | Нет аннотации в раскрытом виде (только обрезанная карточка), нет перехода «от книги к теме» |

Плюс данные: у книги нет своей дисциплины — она выводится только через связи с билетами. Для книг, не привязанных ни к одному билету, фильтр по дисциплине не сработает.

---

## 2. Что предлагаю (MVP, 3 сценария)

### 2.1. Поиск и группировка

- Строка поиска по автору, названию и аннотации (тот же компонент `js/live-search.js`, что на tickets/sections — единое поведение и клавиатура).
- Фильтр-чипы: «Все», «Общая», «Социальная», «Возрастная», «Вне программы».
- Дисциплина книги вычисляется через `ticket_library → tickets.discipline_id`; книга без связей попадает в «Вне программы».
- Сортировка: по алфавиту (как сейчас) или «сначала к билетам».

### 2.2. Связь с билетами

- На карточке — бейдж «К билету №N» (если связей несколько — «+ещё 2»).
- Клик по бейджу ведёт в `tickets.html` с якорем на билет: `?discipline=<id>&ticket=<number>` (механизм deeplink уже есть в `sections-wiki.js`, нужно расширить на tickets).
- В конспекте билета список литературы сделать кликабельным: `library.html?book=<id>` → библиотека открывает книгу (подсветка + раскрытая аннотация).

### 2.3. Карточка книги

- Раскрытие аннотации по клику (сейчас текст обрезан).
- Кнопка «Показать билеты» — фильтр по этой книге.
- Если книга рекомендована преподавателем — бейдж «Рекомендовано» (нужен флаг в данных, см. §4).

---

## 3. Чего НЕ делаем в MVP

- Полных текстов книг и читалки — каталог остаётся каталогом (юридически и по объёму).
- Загрузки PDF и раздачи файлов.
- Рейтингов, отзывов, «прочитано» — это социальный слой, не задача подготовки.
- Отдельной админки: правки идут через Table Editor, как сейчас.

---

## 4. Данные

Схему можно не менять: дисциплина и билеты выводятся из `ticket_library`.

Минимальные добавления (по желанию, отдельной миграцией):

| Поле | Зачем |
|---|---|
| `library.recommended boolean` | бейдж «Рекомендовано преподавателем» и фильтр |
| `library.year`, `library.publisher` | уточнение в карточке (если есть в источниках) |
| `library.tags text[]` | темы внутри дисциплины («память», «личность») — на будущее |

Если флага не будет, сценарий «литература от преподавателя» закрывается частично: показываем всё, что привязано к билетам.

## 5. Этапы

| Этап | Что | Оценка |
|---|---|---|
| L-1 | Поиск по автору/названию/аннотации + пустое состояние | 0,5 дня |
| L-2 | Фильтр по дисциплине (через `ticket_library`) + чипы | 1 день |
| L-3 | Бейджи «К билету №N», переход в билет, deeplink `ticket=` | 1 день |
| L-4 | Deeplink `library.html?book=`, раскрытие аннотации, «Показать билеты» | 0,5 дня |
| L-5 | (Опционально) флаг `recommended`, миграция, бейдж | 0,5 дня |

Итого 3–3,5 дня. Проверки: те же сценарии `scripts/ui-probe.mjs` (поиск, фильтр, переход) + 390/1440.

---

## 6. Критерии приёмки MVP

- На 390 и 1440 по запросу «Рубинштейн» находится книга; по запросу «память» — книги с этим словом в аннотации.
- Фильтр «Общая» показывает только книги, привязанные к билетам общей психологии, и не теряет книги без связей (они в «Вне программы»).
- Клик «К билету №12» открывает нужный билет в tickets.html, а не главную.
- Из конспекта билета клик по книге открывает библиотеку с раскрытой карточкой этой книги.
- Пустая выдача объясняет, что искать можно по автору, названию и аннотации.

## 7. Вопросы

1. Есть ли список «рекомендовано преподавателем» отдельно от привязки к билетам? Если да — нужен флаг в данных.
2. Нужны ли темы внутри дисциплины (теги) или хватит поиска по аннотации?
3. Показывать ли книги без связей с билетами (сейчас они есть в каталоге) — да, но в отдельной группе?
