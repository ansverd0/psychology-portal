## 2. Сводка требований (ИПП, бакалавриат)

| Заголовки | TNR **14**, по центру, без кавычек, без точки, без переноса | 14, по центру |
| Нумерация | сквозная арабскими, включая приложения; на титуле номер не ставится | есть |
| Структура (порядок) | титул (Прил. 3) → оглавление (Прил. 4, 1 стр.) → введение (**1–3 стр.**) → основная часть → **выводы по главам (1 стр.)** и заключение (**1–2 стр.**) → список литературы → приложения | у нас: введение, 2 главы, выводы, заключение |
| Введение | актуальность; объект, предмет, цель, гипотеза и задачи; методы и методики; значимость и область применения | в карте есть |

(«две главы — теория и практика» — сложившаяся практика, а не пункт
положения).

## 3. Работы выпускников прошлых лет: что реально доступно

- **Полных текстов в открытом доступе нет.** Тексты ВКР лежат на
  Образовательном портале за входом (ИАИС), публично — только каталог с
  названием, автором, кафедрой и краткой аннотацией.
- Каталог: 1050 работ, вкладки 2020–2027, фильтр по типу работы (бакалаврская,
  магистерская, специалиста, НКР), поиск по названию или ФИО.
- Что нашлось по словам в названиях: «психолог» — 5 работ, «мотивац» — 8,
  «цифров» — 2, «эмоциональн» — 2, «саморегул» — 2.
- Примеры кафедры психологии ИПП: «Личностные особенности сотрудников МЧС
  первого года службы с разным уровнем социально-психологической адаптации»
  (Белоусова А. Е.); «Связь саморегуляции младших школьников, занимающихся
  хореографией, с особенностями детско-родительских отношений» (Бирюкова С. Д.).
  Обе — по схеме «глава 1 теоретическая + глава 2 эмпирическая».

**Вывод:** читать чужие ВКР как образцы не получится — их нет в открытом
доступе. Ориентир — положение ИПП (структура, объём, оформление) и аннотации
в каталоге. Если нужны именно тексты — просить у научрука или на кафедре
(обычно дают 1–2 работы прошлых лет).

## 4. Хватает ли источников для теории

### Цифры по базам (OpenAlex, фильтр по названию и аннотации)

| Запрос | Работ |
|---|---|
| `"self-regulated learning"` | 24 822 |
| `"learning analytics"` | 18 754 |
| `"Bloom taxonomy"` (и рус.) | 10 596 |
| `"emotion regulation" learning` | 3 536 |
| `"academic motivation" "self-determination"` | 686 |
| `"digital footprint" education` | 550 |
| `"цифровой след"` | 83 |
| `"саморегуляция" "учебной деятельности"` | 39 |
| `"эмоционально-смысловая регуляция"` | **0** |

То есть по конструктам работа опирается на большое поле (англоязычное), но
сам термин из названия темы в базах отсутствует — его научная база держится на
работах Оганесяна и на смежных конструктах (смысл, эмоции, саморегуляция).

### Что есть в черновике

43 источника, все русскоязычные, 1959–2026, основная масса — 2019–2025.
Иностранных источников нет ни одного.

### Оценка по блокам главы 1

| Блок | Состояние | Чего не хватает |
|---|---|---|
| 1.1 Эмоционально-смысловая регуляция | **слабо**: 1 работа Оганесяна + классика (Божович, Леонтьев, словарь) | Выготский (смысл, знак), Рубинштейн (субъект, «внешнее через внутреннее»), ещё 2–3 работы по эмоциональной регуляции учебной деятельности |
| 1.2 Цифровая среда | **достаточно**: 16 статей + книги (Асмаковец, Жданова, Ванновская, Одинцова, Солдатова) | 2–3 англоязычных обзора про цифровую среду и саморегуляцию |
| 1.3 Саморегуляция и её операционализация | **почти достаточно**: Моросанова 2022, Ишмуратова–Моросанова, Прохоров, Перикова, Крылова | **Конопкин** — первоисточник структурно-функциональной модели (без него модель висит в воздухе) |
| 1.3 Мотивация | **достаточно**: Гордеева 2006 + методика 2014, Маркова, Маслоу, Огарева | **Deci & Ryan** — первоисточник теории самодетерминации |
| 1.3 Блум | **пусто**: в списке нет ни одной работы | **Anderson & Krathwohl, 2001** — обязателен, иначе параграф про уровни целей без опоры |
| Цифровой след (мировой контекст) | минимум: 5 работ на русском | 3–5 англоязычных по learning analytics/SRL (например, Anthonysamy et al., 2020, `10.1007/s10639-020-10201-8`; Xu et al., 2025, `10.1111/bjet.13599`) |

### Вердикт

Для 40–60 страниц нужно примерно **50–60 источников**, из них на теорию —
35–45. Сейчас 43: объём почти достаточный, но есть **четыре дыры**, без которых
глава 1 будет слабее, чем выглядит:

1. **Конопкин** — модель саморегуляции, на которую опирается вся
   операционализация метрик.
2. **Deci & Ryan** — теория самодетерминации, на которой стоит ШАМ.
3. **Anderson & Krathwohl (2001)** — таксономия, на которой стоит практикум.
4. **Выготский / Рубинштейн** — смысловая линия темы.

После добавления этих позиций и 5–7 англоязычных работ по SRL/learning
analytics база будет достаточной: расширять до 70 источников не обязательно,
важнее, чтобы на каждый конструкт приходился первоисточник, а не пересказ.

**Риск, который надо решить до письма:** термин «эмоционально-смысловая
регуляция» в базах не встречается. Либо принимаем рамку Оганесяна и явно
говорим, что работа развивает её на материале учебной деятельности, либо
переопределяем понятие через смысл + эмоции + саморегуляцию и тогда
обосновываем это в §1.1. Сейчас в черновике термин не определён.

   поиске OpenAlex).

4. Уточнить, нужен ли отдельный параграф по Блуму в главе 1 или его место — в
   §1.3.
